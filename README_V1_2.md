# ZonaGTA6TV V1.2 — Vice City Futurista

Rediseño visual inspirado en la estética neón tropical/cinemática asociada a GTA 6, sin usar assets propietarios.

Incluye:
- Interfaz futurista, luminosa y dinámica.
- Feed social con glassmorphism y neón.
- Navegación temática Vice City.
- Tendencias, usuarios online y chat LIVE.
- Registro preparado para Google/Email mediante Supabase.
- Perfil y publicaciones.
- Mantiene la arquitectura de Supabase de V1.1.
- Responsive.

Para activar autenticación, publicaciones persistentes y chat real, configura `config.js` con la URL y anon/public key de tu proyecto Supabase y ejecuta el SQL de la V1.1.

GitHub Pages sirve el frontend; Supabase proporciona Auth, Database y Realtime.
