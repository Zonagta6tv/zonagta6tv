# ZonaGTA6TV — V1
Portal fan estático reconstruido desde cero.

## Características
- Sin frameworks, CDNs ni fuentes externas obligatorias.
- Gráficos locales SVG.
- Noticias, blog, guías, rumores/filtraciones y comunidad.
- Comentarios locales con localStorage.
- Búsqueda, modales, contador, parallax 3D y responsive.
- Enlaces a YouTube/TikTok configurados como @ZonaGTA6TV.
- Sustituye `https://www.youtube.com/@ZonaGTA6TV` y `https://www.tiktok.com/@ZonaGTA6TV` en `index.html` si tus URLs reales son diferentes.

## Actualización editorial
La fecha y datos mostrados en esta V1 se basan en información disponible el 30/08/2026. Para mantener noticias realmente automáticas se requiere conectar una fuente/API o un CMS.

## Despliegue
Sube todos los archivos y la carpeta `assets` a la raíz de tu hosting. Abre `index.html`.
