# ZonaGTA6TV — FUTURE V3 // CINEMATIC AAA

Una versión más cinematográfica y dinámica para GitHub Pages.

### Incluye
- Hero 3D con parallax de cursor, HUD y profundidad.
- Glassmorphism, neón, scanlines, grid futurista y microanimaciones.
- Revelado de secciones al hacer scroll.
- Galería modal, buscador, dossiers, quiz y countdown.
- Música ambiental **original** incluida (`assets/future-ambient.wav`), no es música de GTA VI.
- Comentarios locales funcionales sin servidor.
- Preparación para comentarios públicos reales con **Utterances + GitHub Issues**.

### Comentarios públicos reales
1. Crea un repositorio público para esta web.
2. Instala la app Utterances en ese repositorio y habilita GitHub Issues.
3. Abre `app.js`.
4. Busca `const UTTERANCES_REPO="TU_USUARIO/TU_REPOSITORIO";`
5. Sustitúyelo por `usuario/nombre-del-repo`.
6. Sube el ZIP descomprimido a GitHub Pages.

Los comentarios públicos se almacenarán como Issues del repositorio. Si no configuras Utterances, el modo local seguirá funcionando.

### Música
Por derechos de autor, el ZIP no contiene ni reproduce la banda sonora de GTA VI. El archivo incluido es una pieza ambiental original creada para esta interfaz. Si tienes derechos/licencia para una pista concreta, puedes reemplazar `assets/future-ambient.wav`.

### Publicar
Sube el contenido a la raíz del repositorio y activa GitHub Pages desde:
Settings → Pages → Deploy from a branch → main → /(root)

Fan site independiente. GTA VI, Grand Theft Auto y sus marcas pertenecen a Rockstar Games / Take-Two Interactive.
